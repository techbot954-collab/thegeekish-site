Claude Code cloud sessions now come with promo credits

MC
By Mika CircuitDeveloper tools and creator-tech reporter

Based on BleepingComputer reporting and Anthropic-linked Claude Code access details.

Anthropic is nudging more developers to try remote coding sessions that keep running away from the local laptop.

CLOUD CODINGGeekish sourced quick read

Original Geekish context based on the sources linked below.

The short version

BleepingComputer reports Anthropic is offering promotional Claude Code cloud-session credits to eligible paid subscribers: $100 for Pro users and $250 for Max users.

What cloud sessions are

Cloud sessions run Claude Code on Anthropic-hosted infrastructure instead of on the user's local machine. BleepingComputer says users can start sessions from claude.ai/code, Claude apps, or the CLI with claude --cloud.

The deadline details

The report says eligible subscribers must claim the offer by October 7, and remaining promotional balances expire on November 4. After the promo balance is gone, cloud sessions count against normal plan limits.

Geekish take

This is not just a coupon. It is Anthropic trying to make cloud-based coding agents feel normal: start a task, step away, and come back to review the result instead of babysitting a terminal.

Quick takeaways

  • Eligible Claude Pro users get $100 in promotional cloud-session credits.
  • Eligible Max users get $250, according to BleepingComputer.
  • The credits are separate from normal Claude usage limits until the promo balance runs out.
