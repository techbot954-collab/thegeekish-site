Mac Shortcuts is quietly becoming a natural-language automation tool

A fresh Engadget guide is a useful reminder that Apple's Shortcuts app is no longer just an iPhone trick. On Mac, it is becoming a low-friction automation layer.

MC
Updated September 29, 2026

Concise Geekish brief based on Engadget guidance and Apple Support documentation.

What happened

Engadget published a new guide to getting started with Shortcuts on Mac, noting that the app can automate tedious tasks and now lets users set up scripts using natural language.

Apple's own documentation describes Shortcuts as an app for creating task automations called shortcuts. The interesting part is how much friendlier that idea becomes when setup feels closer to describing the workflow than assembling a tiny app by hand.

Why it matters

Automation tools usually split people into power users and everyone else. Natural-language setup narrows that gap: a creator can ask for a repeated export flow, a student can chain research steps, and a small business owner can build simple admin routines without learning a full scripting language.

The catch is still the same as every automation tool: users need to check the steps before trusting them. But as a gateway into practical desktop automation, Shortcuts is getting more interesting.

Quick takeaways

  • Engadget's guide focuses on getting started with Shortcuts on Mac.
  • Apple says Shortcuts creates powerful task automations called shortcuts.
  • Natural-language setup could make desktop automation feel less intimidating.
