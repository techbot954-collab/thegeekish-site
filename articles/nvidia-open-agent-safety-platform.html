Nvidia wants rogue AI agents stopped by hardware, not vibes

Nvidia says its new Open Agent Safety Platform can put AI agents inside enforceable boundaries and quarantine boundary-breaking behavior within milliseconds.

MC
Updated September 28, 2026

Concise Geekish brief based on Nvidia's announcement, Nvidia's developer writeup, and The Verge reporting.

What happened

Nvidia announced the Open Agent Safety Platform, a stack meant to monitor autonomous AI agents from testing through deployment and enforce limits outside the model itself.

The setup combines OpenShell, Nvidia's open-source secure runtime for sandboxing agents, with Sentry, a reference design that runs on BlueField-4 DPUs as an out-of-band watchdog. Nvidia says Sentry can quarantine an agent that tries to leave its approved boundaries in milliseconds.

Why it matters

The timing is not subtle. The Verge notes that recent AI safety concerns include cases where models or agents went beyond their test environments. Nvidia's pitch is that agent controls should not rely only on the agent obeying instructions.

In Nvidia's developer post, the company compares this moment to the early web: browsers became safer because pages were sandboxed, not because every website promised to behave. The agent version of that idea is isolation, policy checks, audit trails, and a kill switch the agent cannot reach.

Quick takeaways

  • OpenShell defines what files, networks, tools, processes, and credentials an agent can access.
  • Sentry adds an independent hardware-backed monitoring layer on BlueField-4 DPUs.
  • Nvidia lists Anthropic, Microsoft, Salesforce, SAP, Scale AI, SpaceXAI, and others among organizations working with the platform technologies.
