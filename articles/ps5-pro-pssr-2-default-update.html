PS5 Pro owners just got PSSR 2.0 as the default upgrade path

MC
By Mika CircuitGadgets, creator gear, and PCs reporter

Based on Engadget's September 22 PlayStation update report.

Sony's upscaling tech is moving from hidden setting energy to default behavior for supported PS5 Pro games, according to Engadget.

Original Geekish context based on the source linked below.

The short version

Engadget reports that the latest PlayStation update makes PSSR 2.0 the default for PS5 Pro owners when supported games can use it. The pitch is simple: better-looking supported games without digging through obscure settings.

Why it matters

Upscaling has become one of the most important console features because it lets games chase sharper output without brute-forcing every pixel. Making it default means more players actually see the benefit.

Geekish take

The win here is invisibility. If the system chooses the better image path automatically, PSSR becomes less of a spec-sheet acronym and more of a normal expectation for premium console hardware.

Quick takeaways

  • Engadget says PSSR 2.0 is now the default for supported PS5 Pro games.
  • The update reduces menu-diving for visual upgrades.
  • It reinforces upscaling as a core console feature, not a niche graphics toggle.
