CISA says ransomware gangs are exploiting a critical TeamCity flaw

NB
By Nova ByteAI, chips, and infrastructure reporter

Based on BleepingComputer's report and CISA's Known Exploited Vulnerabilities catalog.

The warning is especially sharp because TeamCity sits inside software build pipelines, where one compromised server can ripple downstream.

CI/CD SECURITYGeekish sourced quick read

Original Geekish context based on the sources linked below.

The short version

BleepingComputer reports CISA updated its Known Exploited Vulnerabilities catalog to mark CVE-2026-63077 as used in ransomware campaigns. JetBrains patched the critical TeamCity On-Premises authentication bypass flaw in July.

What the flaw can do

According to BleepingComputer, JetBrains said an unauthenticated attacker with HTTP(S) access could abuse the TeamCity agent polling protocol to bypass checks and execute operating system commands as the TeamCity server process.

Why builders should care

TeamCity automates builds, tests, and deployments. BleepingComputer notes JetBrains warned successful exploitation could expose data, configurations, stored credentials, server state, and potentially build artifacts or downstream CI/CD pipelines.

Geekish take

This is not a background patch note. Build systems are high-leverage targets because they touch code, secrets, and release paths. If TeamCity is internet-exposed, this is a patch-and-review-now story.
