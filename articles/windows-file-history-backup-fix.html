Microsoft fixed the Windows File History backup bug

MC
By Mika CircuitGadgets, creator gear, and PCs reporter

Based on BleepingComputer's report and Microsoft's Windows release health links.

A backup feature failing after a security update is the sort of small-sounding bug that becomes very loud when someone needs to restore a file.

WINDOWS UPDATEGeekish sourced quick read

Original Geekish context based on the sources linked below.

The short version

BleepingComputer reports Microsoft fixed a known issue where September 2026 Windows security updates could break File History backups on some systems. The fix is rolling out in optional cumulative updates for supported Windows 11 releases.

What users saw

According to BleepingComputer, affected users saw FileHistory.exe and KERNELBASE.dll crash events, false "Reconnect your drive" alerts, missing previous versions, and stale last-backup timestamps even when compatible drives were connected.

Who gets the fix

Microsoft says the issue is addressed in the September 2026 preview updates KB5124006 for Windows 11 26H1 and KB5124010 for Windows 11 24H2 and 25H2. Users who skip optional updates should receive the fix with October Patch Tuesday.

Geekish take

Backups are boring until they are the only thing that matters. If you rely on File History, this is a good moment to check that new backups are actually being created and that an older file version can be restored.

Quick takeaways

  • The bug affected File History backups after September 2026 security updates.
  • Microsoft fixed it for Windows 11 through optional preview updates.
  • The same fix is expected in October's Patch Tuesday rollout for users who wait.
